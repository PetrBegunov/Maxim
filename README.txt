SECRET INBOX – demo
===================

Spuštění:
1. Rozbalte ZIP.
2. Otevřete index.html v moderním prohlížeči (Chrome, Edge, Firefox).
3. Přihlášení:
   Student: student / student123
   Admin:   admin / admin123

Funkce:
- návštěvník může prohlížet nápady a komentáře
- student může přidávat nápady, hlasovat a komentovat
- admin může mazat nápady/komentáře, zakládat účty a blokovat/odblokovat účty
- hledání, filtrování a řazení nápadů
- demo data se ukládají do localStorage prohlížeče

Důležité:
Jde o prezentační front-end demo bez backendu. Účty ani data nejsou bezpečně uloženy
a nejsou synchronizovány mezi zařízeními. Nepoužívejte skutečná hesla ani citlivé údaje.
